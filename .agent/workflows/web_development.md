---
description: Comprehensive workflow for creating stunning, modern, and high-performance web applications.
---

1. **Plan and Understand**
   - Fully understand the user's requirements.
   - Draw inspiration from modern, beautiful, and dynamic web designs.
   - Outline the features needed for the initial version.
   - Define the technology stack (HTML/JS/CSS for simple, Next.js/Vite for complex).

2. **Set Up Project**
   - If using a framework:
     - Run `npx -y create-vite-app@latest ./` (or similar) in non-interactive mode.
   - If using vanilla stack:
     - Create `index.html`, `style.css`, and `app.js`.

3. **Build the Foundation**
   - Start by creating/modifying `index.css`.
   - Implement the core design system with all tokens and utilities.
   - Use curated, harmonious color palettes and modern typography (e.g., Inter, Roboto).

4. **Create Components**
   - Build necessary components using your design system.
   - Ensure all components use predefined styles, not ad-hoc utilities.
   - Keep components focused and reusable.
   - creative innovative and premium designs.

5. **Assemble Pages**
   - Update the main application to incorporate your design and components.
   - Ensure proper routing and navigation.
   - Implement responsive layouts.

6. **Polish and Optimize**
   - Add subtle micro-animations for enhanced user experience.
   - Ensure smooth interactions and transitions.
   - Optimize performance where needed.
   - Verify SEO best practices (Title tags, Meta descriptions, Semantic HTML).

7. **Final Verification**
   - Verify the application runs locally (`npm run dev` or open `index.html`).
   - Check for any console errors or visual bugs.
